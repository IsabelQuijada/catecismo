# Fotografías de centros de catequesis

Guarda aquí una fotografía optimizada de cada sede o templo donde se reúne el grupo de catequesis. Evita incluir niñas, niños o datos personales visibles.

Cuando estén disponibles, incorpora la ruta de la imagen al contenido del centro correspondiente. Hasta entonces, la interfaz usa fotografías locales temporales de la parroquia.
