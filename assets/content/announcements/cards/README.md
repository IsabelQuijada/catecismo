# Ilustraciones para tarjetas de actividades y avisos

Coloca en esta carpeta las ilustraciones optimizadas para las tarjetas de la sección “Actividades y avisos”.

Assets sugeridos:

- `libros-catequesis.webp`
- `tiempo-adviento.webp`
- `curso-sacramentos.webp`
- `iglesia-encabezado.webp`

Usa ilustraciones watercolor con proporción horizontal cercana a 16:9, sin texto incrustado y con fondo claro. Actualiza `imageKey` del anuncio y el mapeo de imágenes en `src/components/activity-announcements.tsx` cuando agregues cada recurso.
