# Imagen de portada

Guarda aquí la fotografía principal del inicio.

Recomendación:

- Fotografía horizontal de la parroquia, comunidad o una actividad autorizada.
- Mínimo 1600 píxeles de ancho.
- Sin texto integrado: el sitio colocará el mensaje encima o junto a la imagen.
- Usa un nombre descriptivo, por ejemplo `parroquia-san-miguel.jpg`.

No incluyas fotografías de menores sin autorización de uso.
